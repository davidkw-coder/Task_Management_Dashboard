# Task Management Dashboard

A responsive task dashboard built with React, JavaScript, and Vite. Tasks are managed in React state and are available for the current browser session.

## Requirements

- Node.js 20.19+ or 22.12+
- npm

## Install and run

```bash
npm install
npm run dev
```

Open the local URL printed by Vite in your browser.

## Features

- Live total, pending, and completed task summaries.
- Add tasks with a required title, optional description, and priority.
- Mark tasks completed or pending, and delete individual tasks.
- Filter the task list by all, pending, or completed status.
- Responsive layout with validation and empty-state messages.
